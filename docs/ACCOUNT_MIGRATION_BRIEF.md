## 项目定位

这是一个本地、免费、可复现的股票走势研究与世界模型实验项目，不是荐股软件，也不是自动交易系统。

项目已在本地初始化 Git，并将 `main` 推送到公开仓库 `https://github.com/GGBOND-Creator/Stock`。GitHub 只保存已提交且未被忽略的文件；完整迁移仍需复制整个项目目录。

当前主线是：

```text
人的需求 → 满足功能 → 产品/服务功能 → 生产与转化过程
→ 资源、能源、生态和物流约束 → 地理资源观察
→ 企业/产业承载者 → 证券与金融价格映射
```

当前生产试点是“基本营养—动物蛋白—生猪及猪肉供给过程”。企业和证券只能作为下游承载者或金融映射，不能反过来定义人的需求或自然资源事实。

- 不能把 OHLCV 直接解释成产能、单位经济性、权益价值、预期、情绪或大资金净流入。

- 不能把基金经理、管理人或持仓观察直接写成具体交易主体概率。

- 不能把候选资源依赖或空数量观察当成已证实事实。
- 不能在时间序列实验中使用未来可得的数据。
- 不能在没有重新抓取和核验的情况下提供当前市场状态。
