# 股票走势模型：人类使用说明书（零基础、本地版）

最后更新：2026-08-16

## 1. 这个项目是做什么的

这个项目是一间本地“研究实验室”。你把外部股票数据放进来，先转换成统一格式，再让模型从历史数据中寻找有限的统计规律，最后用没有参与训练的较晚数据检查它是否真的学到了一点东西。

它现在不是赚钱机器，也不是选股软件。当前样例结果接近随机猜测，只能说明程序流程曾经跑通。没有投入资金正适合先学习和验证：在模型经得起长期样本外测试以前，不需要承担真实亏损。

## 2. 先认识六个数据字段

一天的股票行情可以先压缩成六个字段：

| 字段 | 中文 | 直观理解 |
|---|---|---|
| `date` | 交易日期 | 这条记录是哪一天 |
| `open` | 开盘价 | 当天开始交易附近形成的价格 |
| `high` | 最高价 | 当天到过的最高价格 |
| `low` | 最低价 | 当天到过的最低价格 |
| `close` | 收盘价 | 当天结束交易附近形成的价格 |
| `volume` | 成交量 | 当天交换了多少股票；来源可能按“股”或“手”计 |

一个最小例子：

```csv
date,open,high,low,close,volume
2026-08-14,10.20,10.55,10.05,10.42,12345600
```

这里能看到价格范围和交易活跃度，但看不到政策、公司消息、买卖双方身份和情绪。模型只能从你给它的信息中学习，所以结果永远是有条件、有限的。

## 3. 三个现在就要知道的金融概念

### 复权

分红、送股、拆分等公司行动会让价格序列出现机械跳变。数据源常提供前复权（`qfq`）、后复权（`hfq`）或不复权（`none`）。不同口径不能随便拼接。若不知道，就记录为 `unknown`，先查清再比较或训练。

### 收益率

模型常关心相对变化而不是绝对价格。一天收益率可粗略写成：

```text
今天收盘价 ÷ 昨天收盘价 - 1
```

例如从 10 元到 10.2 元，收益率约为 2%。

### 成交量单位

A 股资料中的一“手”通常代表 100 股，但数据接口是否已经换算不能靠猜。单位错 100 倍可能不影响某些比例特征，却会破坏跨来源比较和金额推算，所以转换时必须记录来源单位。

## 4. 第一次本地运行

在项目根目录打开 PowerShell。项目已有本地环境时先验证转换器：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

看到 `OK` 表示转换器的基础测试通过。这不是在证明模型有效，只是在证明几种已知数据情况能按预期处理。

如果搬到另一台电脑且没有 `.venv`：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

安装依赖通常需要网络；已有环境和本地 CSV 的日常处理不需要付费服务。

## 5. 导入一份外部数据

### 第一步：保留原件

把外部 CSV/TXT 复制到 `data/inbox/`。不要直接修改唯一原件。假设文件名为 `平安银行日线.csv`。

### 第二步：先弄清来源口径

至少记录：

- 数据从哪里取得；
- 股票代码和市场；
- 是日线还是分钟线；
- 是否前复权、后复权或不复权；
- 成交量按股、手还是未知单位。

不知道的字段写 `unknown`，不要编一个答案。

### 第三步：转换

```powershell
.\.venv\Scripts\python.exe scripts\convert_market_data.py `
  --input "data\inbox\平安银行日线.csv" `
  --output "data\raw\000001.SZ.csv" `
  --source "数据来源名称" `
  --symbol "000001.SZ" `
  --market "A-share" `
  --frequency "1d" `
  --adjustment "unknown" `
  --volume-unit "source_native"
```

转换器会尝试识别常见的中文/英文日期、开盘、最高、最低、收盘和成交量列，也能识别常见 UTF-8、GB18030/GBK 文件及 `万/亿/k/M` 数值后缀。

如果列名很特殊，手动告诉它对应关系：

```powershell
--map date=交易日期 --map open=今开 --map high=最高 --map low=最低 --map close=最新价 --map volume=成交量
```

### 第四步：检查两个输出

- `data/raw/000001.SZ.csv`：模型可读的标准数据。
- `data/raw/000001.SZ.csv.meta.json`：审计记录，包含来源口径、原文件指纹、日期范围、删除行数和警告。

如果显示删除了数据行，不要马上训练。先打开元数据看 `warnings`，再抽查原文件和标准文件的前几行、最后几行。

## 6. 运行当前基础模型

确认数据至少有约 180 个交易日，且口径一致后，可以运行：

```powershell
$env:MPLBACKEND='Agg'
$env:MPLCONFIGDIR=(Join-Path $PWD ".matplotlib")
.\.venv\Scripts\python.exe -m stock_model.train `
  --csv "data\raw\000001.SZ.csv" `
  --symbol "000001.SZ"
```

当前默认问题是：“根据截至今天的基础技术特征，明天收盘相对今天是否上涨？”它会输出模型文件、测试期逐日概率和一张简化回测图。

`MPLCONFIGDIR` 使用当前项目下的可写目录，它不属于模型逻辑。

## 7. 怎样读结果而不被数字骗到

### Accuracy（准确率）

预测方向正确的比例。如果测试期本来就有 55% 的日子上涨，一个永远猜上涨的模型也有 55% 准确率，所以准确率必须和“多数类基线”比较。

### ROC AUC

粗略理解为模型把上涨样本排在下跌样本前面的能力。约 0.5 通常接近随机；越高不代表一定赚钱，也可能来自数据泄漏、样本太小或某一时期偶然有效。

### 样本外测试

训练用较早数据，测试用更晚且未参与训练的数据。股票时间顺序不能随机打乱，否则模型可能间接“看见未来”。

### 回测

让历史数据模拟规则表现。当前项目的回测很简化，尚未完整考虑手续费、滑点、涨跌停、停牌、成交限制和复权，因此不能据此投入真实资金。

最重要的问题不是“这次准确率多少”，而是：

1. 是否明显超过简单基线？
2. 换一个时间段是否仍有效？
3. 加入合理交易成本后是否仍有效？
4. 数据是否可能包含未来信息？
5. 结论能否在另一个标的或下一段时间复现？

## 8. 边建模边学金融的顺序

不需要先读完整本金融教材。建议每一步只学马上要用的知识：

1. 数据转换阶段：OHLCV、交易日、复权、成交量单位。
2. 特征阶段：收益率、波动率、均线，以及“指标只是历史价格的变形”。
3. 标签阶段：预测期限、涨跌阈值、类别比例。
4. 评估阶段：时间切分、基线、过拟合、数据泄漏。
5. 回测阶段：手续费、滑点、停牌、涨跌停、仓位和最大回撤。
6. 扩展现实因素时：公司基本面、行业、政策、流动性和市场预期。

每次可对 AI 这样说：

> 我现在正在做【具体步骤】。先检查本地文件，再只解释完成这一步必须知道的金融概念；把事实、推断和假设分开，并给我一个可验证的小实验。不要给买卖建议。

## 9. 更换账号或电脑

迁移时完整复制整个 `stock` 文件夹，而不是只复制聊天记录或只克隆代码。原始 CSV、模型和部分报告可能被版本控制忽略。

迁移前：

1. 关闭正在写文件的程序。
2. 完整复制项目目录，或压缩后复制。
3. 不把账号密码、Cookie、API 密钥写进项目。
4. 在新位置确认 `AI_HANDOFF.md`、本说明书、`data/`、`models/` 和 `reports/` 都存在。
5. 新电脑重新建立 `.venv`，不要依赖旧电脑环境绝对路径。
6. 运行转换器测试，再让新 AI 阅读交接文档并核对实际文件。

给新账号的第一条消息：

> 请先完整阅读项目根目录 `AI_HANDOFF.md`，再阅读 `docs/USER_GUIDE_CN.md` 和 `docs/DATA_STATUS.md`，并核对实际代码与数据。先用通俗语言告诉我当前能力、风险和一个最小下一步，不要直接推荐股票或交易。

## 10. 安全底线

- 在模型经过长期、滚动、含成本的样本外验证前，不投入真实资金。
- 不借钱、不加杠杆、不使用生活必需资金做实验。
- 不把单次高准确率、漂亮曲线或 AI 的自信语气当作证据。
- 永远保留原始数据、口径说明、转换审计和失败实验。
- 研究结论会随市场制度、参与者和数据分布变化而失效。
