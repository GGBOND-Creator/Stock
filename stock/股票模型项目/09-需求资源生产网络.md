更新时间：2026-08-19

## 方向变化

本项目暂时停止以 A 股上市公司作为产业网络根节点。新的根节点是人的需求，产业和企业是满足需求、利用资源并组织转化的下游承载者；股票只在更下游作为企业权益或金融索取权的映射。旧 A 股网络保留为 `legacy_equity_first_experiment`，用于历史实验和后续映射，不再决定新网络的层级。

```text
人的需求
  → 需求满足方式
  → 产品/服务功能
  → 生产与转化过程
  → 物质、能源、生态和基础设施投入
  → 地理资源禀赋与可获得量
  → 物流、制度和分配约束
  → 企业/产业承载者
  → 证券与金融价格映射
```

这是一种世界模型的组织顺序，不是价格预测公式。需求强度、资源稀缺、企业利润和股票价格必须分别观察；不能把“共振”直接写成涨跌方向。

## 需求总网与当前试点

需求网络现在不把人当作脱离生态的独特个人，而把人类看作具有共同生物基础、又通过群体和文化实现差异化满足的种群。统一根节点是“人类生物种群持续存在与发展”，下分五个相互耦合的系统：

1. **物质代谢与身体稳态**：呼吸、水和电解质、能量与营养、体温、睡眠恢复、排泄、活动、身体完整性、住所防护、卫生防病、疼痛缓解与修复。
2. **繁衍与代际照护**：性与生殖、妊娠出生、依赖者照护、代际知识与能力传递。
3. **神经与心理调节**：情绪与唤醒、可预测性与控制感、感官信息、好奇学习、游戏创造、自主主体感、能力掌握。
4. **依恋与群体协作**：亲密依恋、归属合作、信任安全、承认尊严、 公平互惠、规则秩序、贡献照护。
5. **符号与精神调节**：意义与世界一致性、身份连续性、审美和谐、仪式与超越、死亡哀伤整合、希望与未来投射。

这里的“精神”不是与身体相分离的实体，而是神经系统、语言、长期记忆、依恋、群体协作和死亡意识共同涌现的调节层。宗教、哲学、艺术、教育、仪式和制度是潜在满足方式，不直接等同于需求本体。每个节点保留 `population_scope`，用种群、繁衍群体、社会群体和代际尺度记录，个体只是观察单位。

需求节点的生物基础和剥夺反应目前是模型假设，尚未逐项接入医学、公共卫生、行为科学或人类学来源。`accepted_model_structure` 代表网络结构被接受，不代表机制已经得到实证确认；`cultural_variability` 用于提醒同一需求的满足形式不能跨文化硬编码。

第一条可审计路径为：

```text
基本营养需求 → 蛋白质供给 → 动物蛋白供给 → 生猪及猪肉供给过程
                                     ↘ 饲料粮 / 水 / 土地 / 能源 / 生物条件 / 物流
```

需求、满足方式和过程节点是项目结构定义，不代表已经测得需求量或产量。六类资源/约束目前全部是 `candidate_needs_evidence`，需要独立公开资料后才能升级。牧原股份或其他企业不会成为根节点；未来只能通过 `process_carrier_mappings.csv` 映射到生猪过程，且映射本身也需单独审核。

## 数据契约

数据目录为 `data/human_need_network/`，契约为 `human_need_resource_network_v2`：

| 文件 | 作用 |
|---|---|
| `needs.csv` | 物种/群体尺度的需求树；包含物质与精神调节层 |
| `satisfaction_functions.csv` | 需求满足方式/功能层 |
| `transformation_processes.csv` | 生产与转化过程 |
| `material_resources.csv` | 物质、能源、生态条件和基础设施约束词表 |
| `need_function_edges.csv` | 需求 → 满足功能 |
| `function_process_edges.csv` | 满足功能 → 转化过程 |
| `process_resource_dependencies.csv` | 转化过程 → 资源/约束候选 |
| `resource_endowment_observations.csv` | 资源 × 地理单元 × 观察时间 |
| `process_carrier_mappings.csv` | 过程 → 企业/产业/证券承载者（目前为空） |
| `source_registry.csv` | 候选/已接入数据源登记；来源候选不等于观察事实 |
| `source_observations.csv` | 外部归档观察的标准输入模板，目前为空 |

每条记录都区分 `event_time`、`observation_time` 和 `available_time`。资源丰富度不允许只写 high/medium/low；数量、单位、测量范围、可获得性和质量状态分开保存。空数量只能与 `not_yet_observed` 或 `not_reported` 同时出现，不能自动补零。

## 状态规则

- `accepted_model_structure`：用户确认的模型结构，不是外部事实。
- `candidate_needs_evidence`：候选依赖，只能用于待核验显示，不进入默认事实快照。
- `imported` / `verified`：有可归档来源并通过时点检查的观察或关系。
- `not_yet_observed`：尚未取得数量或可获得性观察；不是零，也不是低水平。
- 企业和股票只能作为过程承载者，不能反向制造需求、资源依赖或资源丰富度事实。

## 快照与使用

```python
from stock_model.human_need_network import build_snapshot, load_network

tables = load_network("data/human_need_network")
snapshot = build_snapshot(tables, as_of="2026-08-18T12:00:00+08:00")
```

默认快照只包含已核验的过程—资源依赖；要检查候选结构可显式使用 `include_candidates=True`。所有过滤均按 `available_time` 执行，防止未来资源观察泄漏到过去。

### 饲料粮来源接入闸门

第一条资源闭环选择饲料粮 `RES_FEED_GRAINS`。当前登记了 FAOSTAT 作物生产、FAOSTAT 食物平衡和中国国家统计局三个候选来源，但它们仍是 `candidate_source`，没有数量进入网络。接入一个来源时，先把原始下载文件另存并记录哈希，再整理为 `source_observations.csv` 所需字段：来源记录 ID、资源 ID、地理单元、观察时间、可得时间、数量、单位和测量范围。

导入命令：

```powershell
.\.venv\Scripts\python.exe scripts\import_resource_observations.py `
  --input data\human_need_network\source_observations.csv `
  --as-of 2026-08-20T00:00:00+08:00
```

只有 `source_registry.csv` 中状态为 `imported` 或 `verified` 的来源才能生成观察；候选来源会被拒绝。观察可得时间早于观察时间也会被拒绝，未来可得观察不会进入更早快照。

## 信息素式显示接口

需求、满足功能、过程和资源节点都使用稳定 ID，因此后续可以接入已有的信息素式状态覆盖层。信号必须继续保持“原始观察—显示强度—证据质量—传播规则”分离：候选资源依赖只能画成候选边，不能因为画面需要而产生浓度或传播；企业/股票映射为空时也不创建虚拟承载者。第一版只重建拓扑和证据状态，不新增任何信号事件或传播规则。

## 下一步边界

“补充完全”在工程上先表示覆盖需求类别和关系边界，不表示一次性完成所有文化、心理和生理测量。下一步只验证一个依赖，例如饲料粮投入或某一流域的用水观察，并保留正式来源、发布时间、地理范围和单位。未完成单一依赖的证据闭环前，不扩展全球资源库，不连接股票价格，也不将候选关系变成信息素传播信号。
