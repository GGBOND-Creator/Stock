# Project instructions for AI agents

Before changing this project, read `AI_HANDOFF.md` completely. It is the current cross-account handoff and operating manual. Then check `docs/DATA_STATUS.md` and the actual code; never infer current market data from an old conversation or snapshot.

Default to local, free, reproducible work. Explain only the finance concepts needed for the current step, distinguish facts from hypotheses, prevent time-series leakage, and never present research output as investment advice. When data contracts or source status change, update `docs/DATA_STATUS.md`; when project direction or handoff state changes, update `AI_HANDOFF.md`.
